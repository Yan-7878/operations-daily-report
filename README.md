# 运营日报自动化工具

上传 Excel/CSV 数据，自动算指标、画图、生成日报。

## 一、安装依赖

打开终端（CMD 或 PowerShell），进入本文件夹，执行：

```bash
pip install -r requirements.txt
```

## 二、运行

```bash
streamlit run app.py
```

浏览器会自动打开一个页面。

## 三、使用

1. 先运行 `python 生成示例数据.py`，会生成一份 `示例数据.csv`。
2. 在页面上传 `示例数据.csv`（或你自己的数据文件）。
3. 页面顶部显示 4 个指标卡片（含环比），右侧显示 3 张图。
4. 点左侧「生成今日日报」按钮，下载 HTML 日报，双击即可用浏览器打开。

## 四、数据文件要求

- 支持 `.csv` 和 `.xlsx` 格式。
- 必须包含以下列（列名要一模一样）：

| 日期 | 在线人数 | 新进入人数 | 付费人数 | 流水(元) | 停留时长(分钟) |
|------|---------|-----------|---------|---------|---------------|

- 「付费转化率(%)」「人均流水(元)」两列可以不用准备，工具会自动计算。
